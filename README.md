# 바캉스 아일랜드

머지 퍼즐 게임으로 자원을 생성·합성하고 미니게임 스테이지를 클리 휴양지를 복구하는 게임입니다.




# 플레이 방법

1. 자원 합성: 자원 하나를 드래그하여 같은 종류와 레벨의 자원이 서로 인접하도록 배치하면 자동으로 합성됩니다.
2. 레벨업: 자원은 1레벨 → 2레벨 → 3레벨 → 4레벨 순으로 진화하며 표시되는 아이콘이 달라집니다(예시: 새싹 → 가지 → 나무 → 가공된 나무).
3. 장애물 격파: 미니게임 스테이지의 하위 기능으로 자원 머지 시 인접한 1칸 범위 내 쓰레기 장애물에 피를 줍니다.
4. 구조물 복구: 특정 자원을 모아 구조물을 건설할 수 있고, 건설된 구조물은 게임 배경에 추가됩니다.




# 실행 방법

# 게임 기능과 기획 의도

- 머지 시스템: 자동 자원 합성을 통해 게임의 메인 콘텐츠이자 시스템을 담당합니다.
- 콤보 시스템: 같은 단계 자원 네 개의 적절한 배치로 달성 가능하며 보너스를 제공해 전략적 플레이를 유도하였습니다.
- 퀘스트 시스템: 여러 종류 목표와 달성 시 즉각적인 보상을 제공하는 콘텐츠로써 플레이 과정에서 자연스럽게 퀘스트를 달성할 수 있도록 설계하였습니다.
- 스테이지 시스템: 한정된 자원을 이용해 단계별로 도전 가능한 미니 스테이지를 클리어하면 즉각적인 보상을 제공합니다.
- 건설 시스템: 자원을 모아 구조물을 건설하는 시스템으로, 플레이어에게 장기적인 목표를 제공하며 건설 진행에 따라 게임 배경이 변화합니다.
- 판매 시스템: 한정된 칸을 최대한 활용하기 위해 불필요한 자원을 판매하고 구조물 건설을 위한 재화를 획득하도록 유도합니다.
- 저장 시스템: 게임 진행 상황을 자동으로 저장합니다.

[문제 구조화]

# 사용 기술 및 개발 도구

- Cursor: 자연어 기반으로 코드를 작성하는 데 사용되었습니다.
- ChatGPT: 스크립트에 에러 발생 시 원인 규명을 위해 사용되었습니다.
- Claude: 스크립트에 에러 발생 시 원인 규명을 위해 사용되었습니다.
- Galaxy AI: 게임 리소스 이미지 생성을 위해 사용되었습니다.
- Stable Diffusion webui: 로컬 기반의 이미지 생성을 위해 사용되었습니다.
- Adobe Photoshop: 게임 리소스 이미지 편집을 위해 사용되었습니다.
