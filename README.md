# 🏝️ 바캉스 아일랜드

머지 퍼즐 게임으로 자원을 생성 및 합성하고 미니게임 스테이지를 클리하며 휴양지를 복구하는 게임입니다.

## 🎮 게임 방법

1. 자원 합성: 자원 하나를 드래그하여 같은 종류와 레벨을 가진 자원과 인접한 1칸에 배치하면 자동으로 합성됩니다.
2. 레벨업: 자원은 1레벨 → 2레벨 → 3레벨 → 4레벨 순으로 진화하며 표시되는 아이콘이 달라집니다(예시: 새싹 -> 가지 -> 나무-> 가공된 트리).
3. 장애물 격파: 미니게임 스테이지의 하위 기능으로 자원머지 시 인접한 1칸 범위 내 쓰레기 장애물에 데미지를 줍니다.
4. 구조물 복구: 특정 자원을 모아 구조물을 건설할 수 있고, 건설된 구조물은 게임 배경에 추가됩니다.

## 🎯 게임 기능

- 머지 시스템: 자동 자원 합성을 통해 게임의 메인 콘텐츠이자 시스템을 담당함.
- 콤보 시스템: 같은 단계 자원 네 개의 적절한 배치로 달성 가능하며 보너스를 제공해 전략적 플레이를 유도함.
- 퀘스트 시스템: 달성 가능한 다방면의 목표와 달성 시 직관적인 보상을 제공하는 콘텐츠로써 플레이 도중 의도치 않은 달성까지 염두하여 개발함.
- 스테이지 시스템: 한정된 자원을 이용해 단계별로 도전 가능한 미니 스테이지 클리어를 통해 직관적인 보상을 제공함.
- 건설 시스템: 자원을 모아 구조물을 건설함으로써 게임의 달성 목표로 기능 및 게임 배경의 변화를 유발해 플레이어의 이탈 방지 역할을 부담함.
- 판매 시스템: 한정된 칸을 최대한 활용하기 위해 불필요한 자원을 판매하고 구조물 건설을 위한 재화를 획득하도록 유도함.
- 저장 시스템: 게임 진행 상황을 자동으로 저장함.
