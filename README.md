# 바캉스 아일랜드

머지 퍼즐 게임으로 자원을 생성·합성하고 미니게임 스테이지를 클리어하며 휴양지를 복구하는 게임입니다.




# 플레이 방법

자원 합성: 자원 하나를 드래그하여 같은 종류와 레벨의 자원이 서로 인접하도록 배치하면 자동으로 합성됩니다.
   
레벨업: 자원은 1레벨 → 2레벨 → 3레벨 → 4레벨 순으로 진화하며 표시되는 아이콘이 달라집니다(예시: 새싹 → 가지 → 나무 → 가공된 나무).
   
장애물 격파: 미니게임 스테이지의 하위 기능으로 자원을 머지할 때 인접한 1칸 범위 내 쓰레기 장애물에 피를 줍니다.
   
구조물 복구: 특정 자원을 모아 구조물을 건설할 수 있고, 건설된 구조물은 게임 배경에 추가됩니다.

# 게임 기능과 기획 의도

- 머지 시스템: 자동 자원 합성을 통해 게임의 메인 콘텐츠이자 시스템을 담당합니다.
  
- 콤보 시스템: 동일한 단계의 자원 네 개가 서로 인접하면 발동하며, 추가 보너스를 제공해 전략적인 배치를 유도합니다.
  
- 퀘스트 시스템: 다양한 목표와 달성 시 즉각적인 보상을 제공하는 콘텐츠로써 플레이 과정에서 자연스럽게 퀘스트를 달성할 수 있도록 설계하였습니다.
  
- 스테이지 시스템: 제한된 자원을 활용해 미니게임 스테이지에 도전하고, 목표 달성에 따른 보상을 획득하는 콘텐츠입니다.
  
- 건설 시스템: 자원을 모아 구조물을 건설하는 시스템으로, 플레이어에게 장기적인 목표를 제공하며 건설 진행에 따라 게임 배경이 변화합니다.
  
- 판매 시스템: 불필요한 자원을 판매해 제한된 공간을 확보하고, 구조물 건설에 필요한 재화를 획득할 수 있습니다.
  
- 저장 시스템: 게임 진행 상황을 자동으로 저장합니다.

# 본인이 담당한 역할

개발 보조: Cursor를 활용한 구현 과정에서 요구사항 구체화 및 오류 수정 참여    




# AI 활용 과정 및 사례

문제 상황 파악: Cursor를 이용해 기존 코드를 수정한 뒤 다른 기능에서 새로운 오류가 발생한 상황을 확인했습니다.  

문제 구조화: 오류가 발생한 기능과 직전에 수정한 기능을 구분하고, 두 기능의 연관성을 검토할 수 있도록 작업 맥락을 정리했습니다.  

AI 교차 검토: 관련 코드와 작업 맥락을 Claude에 전달해 원인을 분석하고 수정이 필요한 구문을 확인했습니다.  

결과 검증: 기존 프로젝트를 백업한 뒤 수정 코드를 반영하고 실행 테스트를 진행했습니다.  




# 사용 기술 및 개발 도구

- Cursor: 자연어 기반으로 코드를 작성하는 데 사용되었습니다.
- ChatGPT: 스크립트에 에러 발생 시 원인 규명을 위해 사용되었습니다.
- Claude: 스크립트에 에러 발생 시 원인 규명을 위해 사용되었습니다.
- Galaxy AI: 게임 리소스 이미지 생성을 위해 사용되었습니다.
- Stable Diffusion webui: 로컬 기반의 이미지 생성을 위해 사용되었습니다.
- Adobe Photoshop: 게임 리소스 이미지 편집을 위해 사용되었습니다.
